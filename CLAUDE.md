# CLAUDE.md

One-page websites for local businesses, each with an AI chat bot that answers questions
and captures leads. See README.md for the folder map, DESIGN.md for how it fits together,
TASKS.md for what's next, WORKFLOW.md for the dev-team agents.

## Commands

```
python -m venv .venv && .venv\Scripts\activate
pip install -r requirements-dev.txt
pre-commit install        # runs ruff, mypy and gitleaks on every commit
ruff check . && ruff format --check .
mypy
pytest
```

CI (`.github/workflows/ci.yml`) runs the same checks plus a gitleaks scan on every PR.

## Rules

- `backend/llm.py` is the only file that calls the AI model.
- `clients/` holds data only (one `config.yaml` per business); no code goes there.
- Secrets come from environment variables only. Never read, print, log or commit `.env`;
  add new variable names to `.env.example` with blank values.
- Never commit `dist/` (generated by `build.py`).
- Every backend module has a matching `tests/test_<module>.py`.
- Code must pass ruff, mypy (strict) and pytest before committing.
- Work on a branch; never push or merge. The human merges.
- Tick tasks in TASKS.md as they are finished. Design changes go in DESIGN.md first.
